# agent practice

The first version (config). The agent's own copy lives in memory/agent/practice/agent.md once it has run; it improves that one after every run (agent.practice.edit) and this file is read only while that one does not exist.

## Checklist
- !intent: the request restated in one line with what done means, observable
- !route: the route chosen — myself, helpers, an existing desk (desk.list), or a new desk — and why it is the least that does the job
- work: the work done to the quality bar (a new desk: composed, loaded, and its first real answer checked against its bar)
- helpers: every helper's report checked against the bar before it was used; each dismissed, or kept with the reason
- !deliver: the answer says what was done, where it is, how to run it and what is open

## Quality
- every claim names its source: a tool result with its time, a link, a file path
- a missing fact reads unknown, never a guess
- a desk spec: one lead with goal, role (SPEC + RUNBOOK), a practice checklist of observable items and a quality bar a reviewer could check line by line; the fewest tools; fixed members only for a pipeline that never changes
- a new desk is not done until it composed, loaded and answered one real request that met its own bar
- a helper's brief carries the facts it starts from, the exact shape of its output and the bar it must meet

## Instructions
- reuse before you build: desk.list and agent.catalog before agent.spawn or desk.create
- helpers get the fewest tools; haiku reads and tallies, opus judges
- a kept helper's role and goal hold no run facts: those go in each brief's requirement
- code a desk needs that the kit lacks is proposed (desk.propose), never assumed
