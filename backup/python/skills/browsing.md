# Browsing a page for a fact

Open the page, take one snapshot, and read it before doing anything else. The snapshot is
the page; guessing at element names without it wastes a step.

Work from what the task actually asks:

- A fact that is already on the page needs no clicking. Read it and report it.
- A fact behind a form needs the snapshot's uid to fill and submit, then a fresh snapshot.
- A page that is still loading needs a wait for the text you expect, not a second open.

Stop as soon as you have the fact. Report the fact itself — not the route you took to it.
