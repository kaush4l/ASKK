# Arithmetic

Do it with a tool whenever the numbers are longer than two digits, or whenever being
wrong would change the answer you give. Mental arithmetic on long numbers is the most
common way a confident answer turns out false.

Independent sums go in one stage so they run together. A sum that needs an earlier
result goes in the next stage.

Check the result against a rough estimate before reporting it. If the tool says 8301 and
your estimate said roughly 8000, that agrees. If it says 830, something was mistyped.
