Answer the question by computing, not by guessing.

1. Write a small JavaScript program that works out the answer. Its last expression is the result; `console.log` shows working.
2. Run it with the tool `run_code` (language `js`).
3. If it fails, read the error, fix the program, run it again.
4. Answer in one or two plain sentences, with the value the program gave.

The program has the language only: no files, no network, no `require`. Never answer a question that needs a calculation without running a program first.
