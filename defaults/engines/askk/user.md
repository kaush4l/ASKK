# Primary goals
- Build powerhouse/askk: a system of engines (prompt = elements) that the user steers by talking to askk.
- askk is the translator/manager; sub-engines do the work (developer for code).

# Preferences
- Terse replies. No commits or pushes without the user's approval. Move files instead of deleting. No secrets stored.
- No hardcoded engine names in core or views. Rules enforced by code beat prompt text.
- UI: glass look, big cards, prompt view over plain card lists.
