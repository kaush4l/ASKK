slugify function:
- lowercase the text

Implementation:
```js
export function slugify(text) {
  return String(text)
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
}
```

Wait — "non-alphanumeric" — should I consider Unicode? The spec says "non-alphanumeric characters". The simplest interpretation: `[^a-z0-9]` after lowercasing. But what about Unicode characters like "é"? Lowercasing "É" gives "é", which is not in a-z0-9, so it becomes a hyphen. That's a reasonable interpretation. The spec is simple, so I'll go with the ASCII interpretation.

Edge cases:
- empty string → ""
- "Hello, World!" → "hello-world"
- "  Multiple   spaces  " → "multiple-spaces"
- "---abc---" → "abc"
- "123" → "123"
- "!!!abc" → "abc"
- "a---b" → "a-b"

Test file: use node:assert/strict, import slugify, run assertions, and exit 0 on success. If an assertion fails, node exits non-zero (uncaught exception). I'll write a simple test runner.
