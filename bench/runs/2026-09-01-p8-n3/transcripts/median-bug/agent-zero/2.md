The bug: for an odd-length list, `middle = len(ordered) // 2` returns the middle element, which is correct for odd lengths. But for even-length lists, it returns the upper-middle element instead of the average of the two middle elements.

Example: [1, 2, 3, 4] → middle = 2 → returns 3, but the correct median is 2.5.

Fix:
```python
def median(numbers):
    """Return the median of a list of numbers."""
    if not numbers:
        raise ValueError("median of an empty list")
    ordered = sorted(numbers)
    middle = len(ordered) // 2
    if len(ordered) % 2 == 0:
        return (ordered[middle - 1] + ordered[middle]) / 2
    return ordered[middle]
```
