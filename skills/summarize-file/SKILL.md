---
name: summarize-file
description: Use when the user asks to condense or summarize a document or file.
---
Read the file in full before summarizing — never summarize from the filename alone.

Open with one sentence stating what the document is, then give the key points as
a short bullet list in the document's own order. Keep the summary under a tenth
of the original's length, and quote exact figures, names, and dates rather than
paraphrasing them. If the file cannot be read, say so plainly instead of guessing.
