# ASKK

Skeleton. Bun + Next.js 15 (App Router, React 19), TypeScript strict,
`output: 'export'` to a static bundle served from the `/ASKK` subpath.

    bun install
    bun dev        # http://localhost:3000/ASKK
    bun run build  # -> out/
    bun run typecheck

Everything before this commit is at the tag `pre-narrated-rebuild`.
Recover any file with `git show pre-narrated-rebuild:<path>`.
