## Published: desk-owned model transport

Agent workers receive no provider catalogue, connection token, or inference configuration in initialization/settings messages. The desk resolves each step’s configured profile and returns a run-scoped handle, context budget and ordered model events. Workers still own their engine, prompt construction and tool loop. Provider requests, completion metadata, retries and structured failures retain their ordering. The broker removes known connection secrets from returned data. This is credential minimization, not a security sandbox for arbitrary same-origin executable code.

Cancellation, ended runs, retired workers and relay-generation changes revoke the relevant sessions. Independent direct inference survives unrelated companion changes. Context discovery is cached by owner/configuration/authority; changes invalidate it without losing scripted-provider progression. Fresh planner, UX and review agents informed this change; review found and corrected direct-route cancellation and repeated-discovery regressions.
