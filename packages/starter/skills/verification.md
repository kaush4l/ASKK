# Verification

Before starting, write down the one observation that would prove the work is done: a command and the output it must print, a page that must show a value, a test that must pass. If you cannot name it, the task is not clear yet; ask.

Evidence is something a tool returned in this task. "It should work" is not evidence. An agent saying it finished is not evidence; the command it ran and the output it got are.

Check the thing that was asked, not a nearby easier thing. If the owner asked for the page to load, a passing unit test does not prove it.

When the check fails, report it as it is. Half done, stated plainly, is worth more than done, stated wrongly.
